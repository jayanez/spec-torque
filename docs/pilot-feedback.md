# Voluntary pilot report / Informe voluntario del piloto

Copy this form locally and share only the fields you choose. Use the public fixture or a small synthetic reproduction. Check all text, filenames, metadata, captures and attachments for sensitive details before sending. Reports may include source excerpts. Share any publication preference explicitly. The maintainer will confirm the receiving channel.

Copia el formulario en local y comparte solo los campos que elijas. Usa el ejemplo público o una reproducción sintética mínima. Revisa el texto, nombres, metadatos, capturas y adjuntos antes de enviarlos. Los informes pueden contener extractos. Indica si autorizas la publicación de algún material. El mantenedor confirmará el canal de recepción.

| Field / Campo | Your observation / Tu observación |
|---|---|
| Random session ID and attempt number / ID aleatorio de sesión y número de intento | |
| Package version or SHA-256, OS version and architecture, client/build / Versión o SHA-256, SO y arquitectura, cliente/build | |
| Installation route and language / Ruta de instalación e idioma | |
| Installation result and last completed step / Resultado de instalación y último paso completado | |
| Time to first navigable assessment / Tiempo hasta el primer análisis navegable | |
| Finding ID or rule, relative file/line, expected result and reason / Hallazgo o regla, archivo relativo/línea, resultado esperado y motivo | |
| Proposal outcome / Resultado de la propuesta | |
| Friction, exact steps and sanitized error / Fricción, pasos exactos y error saneado | |
| Material approved for publication, if any / Material autorizado para publicación, si procede | |

Start timing at the first install command with prerequisites and downloaded files ready. Stop when the first assessment displays a finding you can open. Record setup time separately if observed. Use the same session ID for retries. Record `unknown`, `not attempted` or `partial` where appropriate. Proposal outcomes include `accepted`, `rejected`, `stale`, `abandoned` and `unknown`.

Empieza a medir con el primer comando de instalación, una vez disponibles los requisitos y archivos. Para cuando se muestre un hallazgo del primer análisis y puedas abrirlo. Anota por separado el aprovisionamiento si lo observaste. Usa el mismo ID de sesión en los reintentos y marca lo desconocido, lo que no intentaste y las sesiones parciales.
