# SpecTorque for Claude Code

A native Mod pane, three author/review/refine skills and six read-only MCP tools, all backed by the shared SpecTorque engine. Build and package the repository first, or extract the Claude release archive. In a project, run `claude --plugin-dir /absolute/path/to/spectorque-claude-0.2.1.zip` (or the extracted folder) and then `/spectorque`. The pane runs `node` from `PATH`, which must be Node 22.20+. The pane shows heuristic evidence and requires reviewed differences before writing. No model is called by the pane. See the repository's compatibility matrix for the exact observed validation and remaining client qualification.
