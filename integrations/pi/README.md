# SpecTorque for Pi

Build and package the repository first, then load with `pi --extension /absolute/spectorque/integrations/pi/index.ts` or install the generated package. Run `/spectorque` for scores, a widget, finding selection and reviewed refinements. In headless contexts the command returns a report without triggering a model turn. Three author/review/refine skills are included. No model or credentials are needed for the baseline. Consult the repository compatibility matrix before claiming full host acceptance.
