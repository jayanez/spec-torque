# Museum audio guide handoff

## Requirements

FR-001: The kiosk SHALL restore language selection in ≤ 250 milliseconds.

Guides MAY hand over an idle unit to another visitor.

FR-202 describes the target; firmware 2.4 is already installed.

### Acceptance
- **GIVEN** an active record
- **WHEN** the entry is checked
- **THEN** the system MUST record the result.
