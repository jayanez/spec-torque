# Disponibilidad de taquillas

## Requisitos

FR-001: Los terminales DEBEN mostrar el aforo en menos de 2 segundos.

Las pantallas DEBERÍAN indicar la próxima actualización.

La mayoría de lectores usa una sola pantalla.

### Acceptance
- **DADO** un registro activo
- **CUANDO** se compruebe la entrada
- **ENTONCES** el sistema DEBE registrar el resultado.
